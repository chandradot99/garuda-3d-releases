What's new

    System requirements

    Minimum
    • 64-bit processor
    • 8 GB of memory
    • 20 GB of free disk space
    Recommended
    • 64-bit processor, 8 cores or more
    • 16 GB of memory or more
    • 100 GB of free disk space

    Memory is what limits how many images can be processed at once. 8 GB handles roughly 100 images; large sorties want considerably more.

    Questions

    Does the machine need an internet connection?
    No. GARUDA 3D is built to run with none at all. Map imagery is supplied as offline tile sets held on the machine rather than fetched from a tile server, and nothing phones home.
    What do I need on the machine first?
    Docker. The download contains GARUDA 3D, not Docker itself: on Linux that means the Docker Engine and the Compose plugin, and on Windows and macOS it means Docker Desktop. Install it before running the installer — on a machine with no internet, bring it across the same way. Note that Docker Desktop requires a paid subscription for larger organisations; the Linux engine does not.
    Which bundle do I take?
    The one for the machine's processor. Intel and AMD machines, which is almost every Windows and Linux one, take the Intel/AMD bundle; Apple Silicon Macs and ARM servers take the ARM one. Taking the wrong one is not fatal — Docker will emulate — but it will be noticeably slower.
    How do I check the file arrived intact?
    Compare the SHA-256 shown above with the one you compute after copying. On Windows: certutil -hashfile <file> SHA256. On macOS or Linux: shasum -a 256 <file>. They must match exactly. This is worth doing on a file that crossed onto the machine on a stick, because nothing else will tell you it was truncated.
    Will installing over an existing copy lose my work?
    No. Projects, tasks and annotations live in a separate data directory that an upgrade leaves alone. Take a copy of it first anyway.
    Can I build it myself instead?
    Yes. The source is in the repository and the README covers building and running it with Docker.
    What is this built on?
    GARUDA 3D is derived from WebODM, which is free software under the AGPL-3.0. So is this.
